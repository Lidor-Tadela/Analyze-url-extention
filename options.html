The easy way to add a rule: open a chapter/episode page, click the extension icon, choose “Set up navigation for this page” and click the number in the address that changes between parts. The rule below is written for you. The form on this page is the manual / regex-based alternative.

Add a rule manually (advanced)

A rule is a regular expression tested against the full page URL. It must contain exactly one capturing group, wrapped around the chapter/episode number - use (?:...) for any other group you need. For example ^https://example\.com/show/[^/]+/episode/(\d+)/?$ matches a site.com/thing/episode/N shape, and ^https://example\.com/manga/[^/]+/(\d+)/?$ matches a site.com/thing/N shape. The number can appear anywhere in the URL, not just at the end.

On-page buttons

Off by choice? You can still navigate from the toolbar popup or with the keyboard shortcut. There is also a small “×” on the panel itself that turns this off.

Keyboard shortcut

Default page keys (while the page has focus): → / N for next, ← / P for previous. A global shortcut that works without clicking the page first can be set at chrome://extensions/shortcuts - both are controlled by this same toggle.
